# 🧮 Python GUI Calculator to .EXE

A sleek Python GUI Calculator built with Tkinter, packaged into a standalone `.exe` executable using PyInstaller.

---

## 🚀 Features
- Full calculator UI.
- Standalone `.exe` file (no Python installation required for end-users).
- Custom application icon.
- Running without a background terminal console.

---
